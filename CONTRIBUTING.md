# Contributing to ITRW Film

1. Check the relevant folder README before adding files.
2. Use descriptive filenames and version numbers.
3. Keep research sources and AI prompts beside the related shot or asset index.
4. Update `docs/progress_tracker.md` when a task starts, changes, or finishes.
5. Do not commit large media files unless the team has explicitly agreed on storage.
6. Add source/licensing information for third-party assets.
7. Never commit passwords, API keys, or private personal information.

## Suggested commit messages
- `docs: add Nile research sources`
- `script: revise English narration`
- `storyboard: update shot list`
- `assets: document SH03 generation prompt`
- `edit: record rough-cut review notes`
