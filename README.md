# ITRW Film — The Nile and the Kings of Ancient Egypt

## Project Overview
A 5–8 minute AI-assisted documentary exploring the Nile and the kings of ancient Egypt, ending with a cinematic sequence inspired by the Royal Mummies Parade.

## Project Goals
- Build a historically grounded visual story.
- Document research, script, visual direction, storyboard, AI prompts, audio, editing, and credits.
- Keep production decisions and progress visible to the initiative team.
