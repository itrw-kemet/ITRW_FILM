# ITRW Film — The Nile and the Kings of Ancient Egypt

## Project Overview
A 5–8 minute AI-assisted documentary exploring the Nile and the kings of ancient Egypt, ending with a cinematic sequence inspired by the Royal Mummies Parade.

## Project Goals
- Build a historically grounded visual story.
- Document research, script, visual direction, storyboard, AI prompts, audio, editing, and credits.
- Keep production decisions and progress visible to the initiative team.

## Production Pipeline
1. Research and historical references
2. Script and narration
3. Visual Bible
4. Storyboard and shot list
5. AI asset generation
6. Audio production
7. After Effects and Premiere editing
8. Credits, review, and final export

## Large Files
Do not commit large raw videos, generated clips, Premiere/After Effects caches, or other heavy exports by default. Store them in the team's approved shared storage and add the link and filename to the relevant README. GitHub warns on files over 50 MiB and blocks files over 100 MiB in regular Git repositories; use Git LFS only if the team has agreed on it and understands its storage limits.

## File Naming Convention
Use consistent, sortable names:
- Shots: `SH##_short-description_v01`
- Images: `SH##_short-description_img_v01.png`
- Video: `SH##_short-description_video_v01.mp4`
- Audio: `SH##_short-description_audio_v01.wav`
- Prompts: `SH##_short-description_prompt_v01.md`

Avoid names such as `final-final2-new.mp4`.

## Team Workflow

- Discuss major changes through Issues or Pull Requests when appropriate.
